# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security-sensitive problems.

Instead, report the issue privately to the maintainers with:

- a clear description of the problem
- affected files or flows
- reproduction steps if available
- impact assessment

## Scope

Security-sensitive areas currently include:

- skill installation and local file writes
- canonical repo submission preparation
- any future remote registry or GitHub automation
- legacy sandbox and exchange code still present in the repository

## Response

The project is still early-stage, but reports will be triaged as quickly as possible. Please allow time for confirmation, remediation, and coordinated disclosure.
