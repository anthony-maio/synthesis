# Code of Conduct

## Our Standard

We want Synthesis to be a serious, useful open-source project for people building agent systems in public. That requires a respectful, technically rigorous environment.

Examples of behavior that help:

- giving clear, grounded technical feedback
- assuming good intent while still challenging weak arguments
- keeping discussions focused on the work
- documenting tradeoffs instead of escalating tone

Examples of behavior that are not acceptable:

- harassment, abuse, or intimidation
- bad-faith personal attacks
- repeated off-topic disruption
- publishing private information without permission

## Scope

This applies to project spaces, issues, pull requests, discussions, and any other official community channels tied to Synthesis.

## Enforcement

Project maintainers may remove, edit, or reject contributions and participation that violate this code of conduct.

## Reporting

For conduct problems, contact the project maintainers privately instead of escalating in public threads.
